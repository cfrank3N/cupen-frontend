# cupen-frontend

Frontend that displays and updates data collected from a yearly tournament between friends

### Docs:

- [Routing](https://reactrouter.com/start/data/routing)
- [Rect-Bootstrap](https://react-bootstrap.netlify.app/docs/getting-started/introduction)

## Develop

add a .env file in root and set VITE_API_URL to your API's url.
